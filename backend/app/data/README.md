# Amazon-Focused Skills Taxonomy - Software & Data Science

## 🎯 Overview

This focused skills taxonomy is specifically designed for **Software Engineering** and **Data Science** roles, aligned with **Amazon's career ladder progression** (L4-L7+) while maintaining **SFIA 9.0 compliance** for global interoperability.

## 🏢 Amazon Career Ladder Alignment

### Software Development Engineer (SDE) Track

| Amazon Level | SFIA Levels | Tenure | Core Focus |
|--------------|-------------|---------|------------|
| **L4 (SDE I)** | 1-3 (Follow/Apply) | 0-3 years | Programming fundamentals, code quality, testing |
| **L5 (SDE II)** | 3-5 (Apply/Ensure) | 3-7 years | System design, architecture, project ownership |
| **L6 (Senior SDE)** | 5-6 (Ensure/Initiate) | 7-12 years | Technical leadership, strategy, mentoring |
| **L7+ (Principal)** | 6-7 (Initiate/Strategy) | 12+ years | Strategic direction, organizational impact |

### Data Science (DS) Track

| Amazon Level | SFIA Levels | Tenure | Core Focus |
|--------------|-------------|---------|------------|
| **L4 (DS I)** | 1-3 (Follow/Apply) | 0-3 years | Statistical analysis, data exploration, basic ML |
| **L5 (DS II)** | 3-5 (Apply/Ensure) | 3-7 years | Advanced modeling, MLOps, business impact |
| **L6 (DS III)** | 5-6 (Ensure/Initiate) | 7-12 years | Research & development, technical leadership |
| **L7+ (Principal DS)** | 6-7 (Initiate/Strategy) | 12+ years | ML strategy, organizational impact, innovation |

## 🔄 Career Transition Paths

### From SDE to Data Science
1. **L4-L5**: Add DAAN, STAT, MLEA skills
2. **L5-L6**: Develop DEEP, NLPS specialization
3. **L6+**: Combine ARCH with ML strategy

### From Data Science to SDE
1. **L4-L5**: Strengthen PROG, SYSD, AWSP
2. **L5-L6**: Add ARCH, system design skills
3. **L6+**: Develop TMLP, technical leadership

### Cross-Functional Growth
- **L5**: Add complementary skills from other track
- **L6**: Develop dual expertise (Full-stack DS or ML-aware SDE)
- **L7+**: Strategic leadership across both domains

## 🏆 Promotion Requirements by Level

### L4 → L5 Promotion
- **Technical**: Master core programming skills (PROG)
- **AWS**: Demonstrate cloud proficiency (AWSP)
- **Impact**: Own complete features or analysis projects
- **Leadership**: Mentor junior team members

### L5 → L6 Promotion  
- **Technical**: System design skills (SYSD, ARCH)
- **Leadership**: Technical leadership (TMLP)
- **Impact**: Cross-team collaboration, strategic projects
- **Innovation**: Drive technical improvements

### L6 → L7+ Promotion
- **Strategic**: Organizational impact (ARCH, TMLP)
- **Leadership**: Influence beyond immediate team
- **Innovation**: Industry-level contributions
- **Business**: Revenue/efficiency impact

## 📚 Learning Recommendations by Level

### L4 (Entry Level)
1. **Foundations**: Master programming fundamentals
2. **AWS**: Complete AWS certifications (Solutions Architect Associate)
3. **Data**: Learn SQL and basic statistics (for DS track)
4. **Best Practices**: Code quality, testing, documentation

### L5 (Mid-Level)
1. **System Design**: Design patterns, scalability principles
2. **Advanced AWS**: Specialized services, optimization
3. **ML/Analytics**: Advanced modeling techniques (DS track)
4. **Leadership**: Technical mentoring, project management

### L6 (Senior Level)
1. **Architecture**: Distributed systems, enterprise patterns
2. **Leadership**: Team management, strategic thinking  
3. **Specialization**: Deep expertise in chosen domain
4. **Innovation**: Research, patents, industry contributions

### L7+ (Principal Level)
1. **Strategy**: Business alignment, technology roadmaps
2. **Influence**: Industry leadership, external speaking
3. **Innovation**: Breakthrough technologies, research direction
4. **Organization**: Culture building, talent development
